# 🤖 AI Data Parser & Automated Assistant Bot (Python)

A next-generation Python automation tool powered by advanced language models (OpenAI/Anthropic APIs) designed to read, analyze, and extract key insights from raw, unstructured data files automatically.

---

## 🚀 Key Features
*   **Intelligent Parsing:** Automatically extracts critical metrics and action items from chaotic `.pdf`, `.txt`, or `.csv` files.
*   **AI API Integration:** Built-in connection handlers for OpenAI (GPT-4) and Anthropic (Claude) architectures.
*   **Automated Summaries:** Generates concise executive summaries and business briefs from long logs without manual reading.
*   **Custom Prompts System:** Easy-to-configure prompt templates to customize how the AI analyzes your specific local business data.
